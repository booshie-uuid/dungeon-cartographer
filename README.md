# DUNGEON CARTOGRAPHER

A map generator for 2D tile based dungeons that uses a meta grid to provide a sense of purpose and structure amongst an otherwise chaotic labyrinth of rooms.

I like chaotic proceedurally generated dungeons, but it always drives me nuts when I see weird anomalies like pinched corners or walls that are slightly out of alignment. This map generator tries to solve this problem by using a meta grid with a tartan-style pattern of randomly sized bands, allowing for rooms of all different dimensions, while still ensuring that walls remain aligned to a consistent grid.

Includes a basic test bed that allows you to play with different parameters and see a quick and simple preview of maps, or to explore the maps in a fully rendered tile mode.
